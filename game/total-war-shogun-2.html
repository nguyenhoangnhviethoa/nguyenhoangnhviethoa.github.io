Giới thiệu bản Việt hóa

Việt hóa Total War: SHOGUN 2 bản Steam, gồm cả hai bản mở rộng Rise of the Samurai và Fall of the Samurai. Dịch toàn bộ chữ trong game, lời cố vấn và cả Bách khoa (wiki trong game) bằng AI, có soát lại câu chữ. Có font tiếng Việt và bộ cài tự động: chỉ thêm một file chữ, không đụng tới file save, gỡ ra là trả lại game gốc. Phát hành miễn phí.

Đã dịch những gì

  • Toàn bộ chữ trong game: Shogun 2, Rise of the Samurai, Fall of the Samurai
  • Lời cố vấn
  • Bách khoa (wiki trong game) — hơn 1.500 trang
  • Giao diện, menu, nhiệm vụ, sự kiện
  • Font tiếng Việt có dấu

Hướng dẫn cài đặt

  1. Tải file zip và giải nén
  2. Thoát hẳn game
  3. Chạy CaiVietHoa_Shogun2.exe (Windows cảnh báo thì bấm More info → Run anyway; game nằm trong Program Files thì bộ cài sẽ xin quyền Administrator)
  4. Bộ cài tự tìm thư mục game; không thấy thì bấm "Đổi…" và chọn thư mục game (Steam: chuột phải Total War: SHOGUN 2 → Manage → Browse local files)
  5. Bấm "Cài Việt hóa", đợi chạy tới 100%
  6. Mở game là có tiếng Việt — giữ ngôn ngữ game là English, không cần đổi gì
